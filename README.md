# Road-Accident-Analytics
Interactive Power BI dashboard for analyzing road accident trends, casualties, vehicle involvement, and safety insights using real-world traffic data.
This project helps identify accident patterns and provides insights for improving transportation safety and decision-making.

---

## 📌 Project Overview

The dashboard provides detailed analysis of:

- Total casualties and accidents
- Fatal, serious, and slight casualties
- Monthly casualty trends (Current Year vs Previous Year)
- Casualties by vehicle type
- Urban vs Rural accident distribution
- Day vs Night accident analysis
- Casualties by road type
- Top locations with highest casualties
- Weather and road surface impact analysis

## 📈 Key Insights

- Majority of casualties occur in **urban areas**
- **Cars** contribute to the highest number of casualties
- Most accidents happen during **daytime**
- **Single carriageways** record the highest accident counts
- Certain cities consistently show higher casualty rates
